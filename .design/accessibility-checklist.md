# Accessibility Checklist

- Task buttons are real buttons and keyboard focusable.
- Button text starts with an action.
- Text does not rely on color alone.
- First screen works at 1366x768 without requiring documentation.
- Format chips are readable at mobile width and wrap instead of clipping.
- Safety copy is visible before users add files.
- No oversized text inside compact panels.
- Drag-and-drop is not the only path; file picker remains available in composer.
- The first screen does not expose expert-only technical terms.
