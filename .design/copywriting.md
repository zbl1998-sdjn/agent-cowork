# Beginner Copywriting

## Approved First Screen Copy

- 今天要交付什么？
- 不会 Office 也没关系，把文件拖进来，选一个任务就能开始。
- 拖文件到这里：Word、Excel、PPT、PDF、图片、TXT、CSV、ZIP。
- 默认只生成副本，不会改你的原文件。
- 常用成果格式：Word、Excel、PPT、PDF、可复制文本、CSV。

## Format Rule

Do not make Markdown or HTML the only visible output. They can exist as fallback or advanced formats, but the primary user-facing formats must be DOCX, XLSX, PPTX, PDF, TXT, and CSV.
