# Beginner Office User Journey

## Open App

The user sees "今天要交付什么" and large task buttons instead of a blank chat page.

## Add Materials

The user drags Word, Excel, PPT, PDF, image, TXT, CSV, or ZIP files into the file basket. The app explains this only adds local materials and does not change the original files.

## Choose Task

The user selects one task:

- 写周报
- 表格急救
- Word 改正式
- 做 PPT
- 会议纪要
- 老板让我整理一下
- 我也不知道该怎么弄

## Confirm Goal

The app sends a plain-language request to the assistant. The request includes the expected output formats and the rule to save copies.

## Preview And Save

The user sees a preview of created files and clear buttons such as 打开 Word, 复制正文, 导出 PDF, 导出 Excel.

## Failure Path

If generation fails, the user still gets a TXT or DOCX-style draft and three recovery choices: 重试, 换成简化模式, 导出草稿.
