# Agent Cowork 2.3 Beginner Office Brief

## Goal

Make the first screen usable for non-technical office users. Users should understand that they can drag in office files, choose a daily task, and receive a normal office deliverable without learning prompts, model settings, Markdown, HTML, or paths.

## Scope

- Beginner home empty state.
- File basket entry copy.
- Office rescue and daily task templates.
- Deliverable format promises.
- Friendly safety copy.

## Non Goals

- Keep backend work limited to built-in, approval-gated beginner office recipes.
- No original file overwrite.
- No automatic external sending.
- No expert model/provider controls on the first screen.

## Acceptance

- First screen avoids technical words such as MCP, token, API, JSON, shell, workspace root, vector index, model router, and prompt cache.
- First screen offers Word, Excel, PPT, PDF, TXT, CSV, and image/PDF input expectations.
- Every suggested task maps to a common office output format.
- The safety message says original files are not modified by default.
