# Agent Cowork 安装与使用说明

面向首次使用的用户。Agent Cowork 是一个**本地宿主办公智能体**:文件和执行能力受本机 Host 控制。当前 Internal Beta 的模型执行限本机 Ollama/LM Studio 或管理员明确放行的客户网关；公网云 provider 在审批回执消费链完成验收前会 fail-closed。

> 适用范围:个人电脑本地使用。请勿把它暴露到公网或当作多人共享的服务器。

---

## 一、安装

1. 当前项目只产出 NSIS `setup.exe`；安装前运行 `Get-AuthenticodeSignature <安装包.exe>`，只接受 `Status=Valid` 且发布者与分发方一致的版本。
2. 双击已验证的 `setup.exe`,按提示完成安装。安装后桌面/开始菜单会出现 **Agent Cowork** 图标。
3. 未签名、自签名或显示未知发布者的仓库内构建仅供开发验证，不是生产分发件；不要通过“仍要运行”绕过 SmartScreen。

---

## 二、首次启动

1. 打开 **Agent Cowork**,会先看到登录界面。两种方式:
   - **注册 / 登录**:用一个用户名 + 密码(至少 6 位)。账户只保存在本机,用于区分多人的数据。
   - **跳过登录(游客)**:点"跳过,先在本地使用"即可立即开始。游客数据同样保存在本机。
2. 进入主界面后,顶部能看到你的身份和"⚙ 设置"。

---

## 三、配置本地模型(让它能对话)

使用 Ollama 或 LM Studio 等本地 provider 不需要 API Key，也是当前 beta 的默认可用路径。Kimi/Moonshot 等公网云 provider 目前只提供目录/配置发现，即使保存凭据也不会直接出站。

1. 在本机启动 Ollama 或 LM Studio，并准备好要用的模型。
2. 点右上角 **⚙ 设置 → API**，选择 `ollama`/`openai/local`，Base URL 使用本机回环地址并填写实际模型名；API Key 留空。
3. 点 **保存**。客户网关需要管理员先加入 `KCW_CUSTOMER_MODEL_GATEWAY_HOSTS` 精确 allowlist。

> 安全说明:Windows 上保存的凭据由当前用户 DPAPI 封印后写入 `.AgentCowork/config.json`，界面和日志不回显明文。当前 beta 仅允许本地端点或管理员 allowlist 内的客户网关；公网云端点在凭据发送前即被拒绝。

---

## 四、基本使用

- **对话**:在底部输入框直接说你的需求,例如"把这个文件夹里的 CSV 汇总成表格"。
- **斜杠命令**:输入 `/` 可快速调用命令(新建对话、设置、切换面板等)和任务模板。
- **@ 引用文件**:输入 `@` 可引用工作区里的文件。
- **文件改动需确认**:当它要写文件或运行命令时,会先弹出请求,你点同意才执行(可在顶部开"自动批准",但高风险操作仍逐次确认)。
- **产物**:它生成的文件会出现在"产物"面板,可"在系统中打开";图片/Markdown/PDF 也能在对话里直接预览。
- **多对话**:左侧栏可新建、搜索、置顶、导出、删除对话;登录用户的对话会按账户保存。
- **设置中心**:账户、外观(浅色/深色)、模型、API、以及"自检"(查看安全与运行状态)。

---

## 五、常见问题

- **一直转圈/没反应**:先确认 Ollama/LM Studio 已启动、Base URL 是回环地址且模型名存在；客户网关还需管理员 allowlist。公网 provider 当前会返回明确的 fail-closed 错误，而不是可用路径。
- **提示"模型服务暂时不可用,已启用熔断保护"**:上游模型接口连续失败触发了保护,稍等片刻再试。
- **重启后看不到旧的注册账户/游客数据**:账户和未过期会话应持久化在本机 SQLite；若存储初始化或迁移失败，Host 会拒绝启动而不会静默切换为内存身份库。请保留错误日志并联系维护者，不要删除数据库排障。
- **想换工作目录**:Kimi 只能在你授权的"工作区根目录"内读写,其外的文件会被拒绝(这是安全设计)。

---

## 六、安全与隐私

- 所有文件操作都被限制在你选择的**工作区根目录**内;指向目录之外的软链接/越权路径会被拒绝。
- 本机服务默认要求登录令牌才能调用接口,且不信任伪造的身份头。
- 上传会拒绝 `.exe/.bat/.ps1/.html/.svg` 等可执行/主动内容类型。
- 日志会自动按大小轮转,不会无限增长。
- 仅监听本机回环地址(127.0.0.1),不对外暴露。

如需把它用于多人/联网场景,请联系维护者——那需要额外的部署加固(关闭游客免登录、启用 JWT、代码签名等)。
