# Phoenix Scan 工具介绍

> 文档生成日期:2026-06-07 · 内容依据 Phoenix Scan 仓库(`pyproject.toml` / `README.md` / CLI)整理。

## 一句话定位
Phoenix Scan(`phoenix-scan`，v2.0.0)是一款**生产级、面向授权测试的动态应用安全扫描框架(DAST)**:对**正在运行的 Web/API 目标**发请求探测漏洞,采用插件化架构 + 异步高并发引擎,可选由本地 gemma4 大模型担任"总调度智能体"。

## 核心特性
- **插件化架构,50+ 独立扫描插件**:按需加载、无"上帝类";覆盖 Web / API / 认证 / 高级漏洞四大类。
- **异步并发引擎**:基于 `aiohttp`,连接池 + 自动重试 + 限流。
- **AI 总调度(可选)**:默认尝试启用本地 gemma4 vLLM 作 StrategyBrain(由模型决定扫描阶段与策略);连不上时**自动优雅降级**为标准确定性流程,不影响出结果。
- **保守 / 激进 双模式**:`--mode conservative`(默认,仅检测)/ `aggressive`(真实利用确认)。
- **能力闸门(默认全关,需显式开启)**:`--allow-exploit`(利用确认)、`--allow-oast`(外联回连)、`--allow-bruteforce`(弱口令)、`--allow-destructive`(破坏性)、`--allow-post-exploit`(后渗透)。
- **任务画像 profile**:`ci` / `bug_bounty`(保守版)/ `redteam`(激进版)/ `lab` / `custom`。
- **OAST 外带检测**:内置回连服务器,做盲注 / SSRF 等带外(out-of-band)验证。
- **证据链 Proof Pack**:每次扫描产出可复验的证据包(`manifest.json`)。
- **合规映射**:OWASP Top 10 / CWE / 等保 2.0 / CVSS v3 向量与风险评级矩阵。
- **多形态报告**:JSON + HTML + Markdown。

## 检测能力(部分)
SQLi(报错 / 布尔盲注 / 时间盲注 / UNION)、XSS(反射 / 存储 / DOM)、命令注入、LFI / 路径遍历、SSRF、SSTI、XXE、反序列化、XPath / LDAP / NoSQL 注入、开放重定向、CSRF、IDOR / 越权、敏感信息泄露、安全响应头 / CSP、CORS、JWT、OAuth、缓存投毒、HTTP 请求走私、原型链污染、文件上传、GraphQL / WebSocket / gRPC、云原生 / K8s 等。

## 运行模式与安全边界
- **默认保守**:不开任何破坏性能力,只做检测,适合首次摸底。
- **非回环目标必须显式 `--scope`**:`127.0.0.1` 等本地靶场可直接快速验证;公网 / 真实目标须先 `scan-plan` 生成 scope。
- **授权前提**:工具定位为"授权安全测试",使用者须对目标拥有合法授权。

## 常用命令
- `python main.py quick-demo` — 内置 mock 靶场一键演示(产出 proof)。
- `python main.py start-here` / `scan-plan TARGET` — 起步向导 / 生成 scope 模板。
- `python main.py scan TARGET [--mode --strategy --profile --modules --allow-* --auth --auto-auth]` — 主扫描。
- `python main.py agent-attack` — 全自动授权验证 Agent(规划 → 分批扫描 → replay/verifier 汇总)。
- `python main.py intruder / repeater / replay / proxy` — 类 Burp 的参数爆破 / 重放 / 代理。
- `python main.py template-scan` — Nuclei 风格 YAML 模板扫描。
- `python main.py waf-detect / subdomain-enum / fleet-scan` — WAF 识别 / 子域枚举 / 多目标并发。
- `python main.py validate-result / diff / report` — 可信度校验 / 两次结果对比 / 报告生成。
- `python main.py dashboard` — Web 仪表盘(FastAPI + 实时 WebSocket)。

## 产物位置
报告与证据写入仓库 `reports/`:`*_report.html` / `*.md` / `*.json`,以及证据包 `reports/proof_pack/<scanId>/manifest.json`。

## 技术栈
Python 3.12+;`aiohttp`、`playwright`、`beautifulsoup4`、`jinja2`、`flask`、`fastapi`/`uvicorn`、`cryptography`、`h2` 等。
