Agent Cowork对比腾讯 WorkBuddy

两款定位几乎重合的产品:都在本地跑、都把"帮你把办公活干完"当卖点、都支持多模型与 MCP。差别不在方向,而在安全边界的深度、模型与自托管的开放度,以及生态与厂商背书的成熟度。

对比口径:Agent Cowork 数据取自本仓库 README(一手);WorkBuddy 数据取自官网 + 第三方评测(截至 2026-07,标注见文末)。

一句话结论:Agent Cowork 的护城河是可审计的安全治理 + 开源自托管 + 更宽的模型选择;WorkBuddy 的护城河是腾讯背书 + 成熟的集成生态 + 多 Agent 编排的产品化程度。选型取决于你更看重"可控与可自托管"还是"开箱即用与生态"。

双向差异化 — 各自的护城河

Agent Cowork 更强的地方

  • 可审计的安全治理:5 档安全模式 + 出口网关审计 + 逐次审批 + 路径 jail + 提示注入检测,是"可控/可自托管"场景的硬优势(评测指 WorkBuddy 无自动审批与数据驻留保证)。
  • 开源 + 自托管:MIT 许可、源码可审计、可私有部署(SQLite/PostgreSQL 双后端),不绑定单一云。
  • 模型开放度:22 家 provider + BYO-key + fallback 熔断,接 models.dev 实时更新,远多于 WorkBuddy 的 5 家。
  • 工程韧性与评测:CircuitBreaker / BudgetGuard / Checkpoint 续跑 + token/成本 trace + 红队评测门禁,可观测性成体系。

WorkBuddy 更强的地方

  • 厂商背书与成熟度:腾讯出品、已正式发布并商业运营,稳定性与支持是独立项目短期难比的。
  • 集成生态广:GitHub/Jira/Notion/Drive/Slack + 微信/飞书/钉钉/QQ/Telegram,能直接从企业 IM 派发任务,贴合国内团队工作流。
  • 多 Agent 编排产品化:多窗口多 Agent 并行是其核心卖点,编排成熟度高。
  • 开箱即用:20+ 技能包 + 云生态,普通团队上手成本低,无需自建后端。
